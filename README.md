# ClipLite

ClipLite is a lightweight clipboard launcher built with Tauri, Vue3, TypeScript and SQLite.

Inspired by:

* Ditto
* Raycast
* PowerToys Run

## Product Position

ClipLite is NOT a clipboard management application.

ClipLite is a clipboard launcher.

Main workflow:

Ctrl + Alt + V
↓
Search clipboard history
↓
Select content
↓
Paste
↓
Hide launcher

The goal is speed, simplicity and keyboard-first workflow.

## Features

### Clipboard

* Clipboard history
* Search
* Favorites
* Frequent items

### System

* Global shortcut
* System tray
* Auto paste
* Startup support

### UI

* Compact launcher layout
* Separate settings window
* Simplified Chinese
* English
* Theme support
